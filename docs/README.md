
# 흐름에 따른 미션 이해
1. `안녕하세요! 우테코 식당 12월 이벤트 플래너 입니다.` 라는 문구로 시작
2. `12월 중 식당 예상 방문 날짜는 언제인가요? (숫자만 입력해 주세요!)` 문구로 입력 받음
    1. 입력에 대한 유효성 검증
    2. 해당일이 무슨요일인지 체크
    3. 해당일이 별이 있는 날인지 체크
    4. 해당일이 크리스마스 디데이가 있는지 체크
3. `주문하실 메뉴를 메뉴와 개수를 알려 주세요. (e.g. 해산물파스타-2,레드와인-1,초코케이크-1)`  문구로 입력 받음
    1. 입력에 대한 유효성 검증
    2. 음료만 있는지 체크
    3. 주문한 총 개수가 20개 넘는지 체크

4. 주문 메뉴 출력
5. 할인 전 총주문 금액 출력
    1. 주문 메뉴에서 메뉴와 개수로 계산 후 결과
6. 증정 메뉴
    1. 할인 전 총 금액이 12만원 이상일 시 샴페인 증정
7. 혜택 내역 체크
    1. 당일의 정보를 가지고 체크
    2. 증정 이벤트 여부 체크
8. 총 혜택 금액
    1. 혜택 내용 정보로 금액 계산
9. 할인 후 예상 금액 결제
    1. 할인전 총주문 금액 - 총혜택 금액
10. 12월 이벤트 배지 여부
    1. 혜택 금액에 따라 별, 트리, 산타 증정

12 월 이벤트 계획 ( 12월 1일 ~ 12월 31일 )
- 크리스 마스 디데이 할인 : 1000원씩 100원 올라감 ( 12월 1~ 12월 25일까지)
- 평일 할인(일~목) : 디저트 2023 할인
- 주말 할인(금토) : 메인 2023원 할인
- 특별 할인 : 달력에 별이 있으면 1000원 할인
- 증정 이벤트 : 12만원 이상 샴페인 1개 증정

혜택 금액에 따른 12월 이벤트 배지
- 5천원 이상 : 별
- 1만원 이상 : 트리
- 2만원 이상 : 산타

이벤트 주의 사항 :
- 10,000원 이상부터 이벤트 적용
- 음료만 주문시 주문 할 수 없음
- 메뉴는 한번에 최대 20개까지 주문 가능

# 🛠️ 기능 구현

날짜 입력 유효성
- [x] 숫자가 아니라면 예외
- [x] 1~31 사이의 숫자가 아니라면 예외 발생
  - [ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요.

## Domain
### 주문 메뉴들
> 주문한 메뉴들 검증
- [ ] 주문한 메뉴들 형식이 다른 경우 에외 발생
  - 주문한 메뉴들 형식(음식-주문수,음식-주문수..) 
  - [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
- [ ] 쉼표(,) 로 각각 주문한 메뉴 구분
- [ ] 주문한 메뉴들 20개 초과면 예외 발생
  - [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
- [ ] 음료만 있다면 예외 발생
  - [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
- [ ] 중복 메뉴를 입력한 경우
  - [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.

### 주문 메뉴
> 주문한 메뉴를 검증 
- [ ] 주문한 메뉴 형식이 다른 경우 에외 발생
  - 주문한 메뉴 형식(음식-주문수)
  - [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
- [ ] 하이픈(-) 으로 주문 메뉴와 주문 개수 구분 
- [ ] 메뉴판에 없는 메뉴 입력시 예외 발생
    - [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
- [ ] 메뉴의 개수가 0일때 예외 발생
    - [ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.
